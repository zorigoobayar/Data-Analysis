# Олон хүчин зүйлийн шугаман регрессийн шинжилгээ

Энэ бүлэгт олон хүчин зүйлийн шугаман регрессийн үндсэн ойлголт, загварын байгуулалт, коэффициентийн тайлбар, таамаглалын шалгалт болон Respiratory чиглэлийн судалгаанд хэрэглэх практик жишээг байрлуулна.

## Суралцах зорилго

- Хамааралтай болон үл хамааралт хувьсагчийн ялгааг ойлгох.
- Олон хүчин зүйлийн шугаман регрессийн загварыг томьёолох.
- Регрессийн коэффициент болон тохируулсан дундаж ялгааг тайлбарлах.
- Хольж нөлөөлөгч хүчин зүйл (confounding), харилцан үйлчлэл (interaction)-ийг авч үзэх.
- Загварын таамаглалууд болон үлдэгдлийг шалгах.
- R программ ашиглан загвар байгуулж, үр дүнг тайлагнах.
