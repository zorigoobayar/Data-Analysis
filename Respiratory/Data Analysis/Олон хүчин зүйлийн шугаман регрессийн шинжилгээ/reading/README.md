# Унших материал

[← Бүлгийн үндсэн хуудас](../README.md)

## Агуулга

1. Олон хүчин зүйлийн шугаман регрессийн үндсэн ойлголт
2. Регрессийн загвар ба тэгшитгэл
3. Хамааралтай болон үл хамааралт хувьсагч
4. Регрессийн коэффициент ба түүний тайлбар
5. Нэг болон олон үл хамааралт хувьсагчтай загварын ялгаа
6. Хольж нөлөөлөгч хүчин зүйл (confounding) ба Venn diagram
7. Категорийн хувьсагч, dummy coding ба reference бүлэг
8. Харилцан үйлчлэл (interaction) ба шугаман бус хамаарал
9. Загварын таамаглалууд: шугаман хамаарал, үлдэгдлийн хэвийн тархалт, дисперсийн тогтмол байдал, бие даасан байдал
10. Олон шугаман хамаарал (multicollinearity) ба VIF
11. Үлдэгдэл, leverage болон нөлөө ихтэй ажиглалтууд
12. Загвар сонгох, model building болон үр дүн тайлагнах

> Ном, өгүүлэл болон бусад эх сурвалжийн дэлгэрэнгүй унших материалуудыг энэ хэсэгт тусдаа Markdown файлаар нэмнэ.
