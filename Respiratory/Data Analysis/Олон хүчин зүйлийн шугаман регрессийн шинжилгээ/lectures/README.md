## Лекцийн дараалал

1. Олон хүчин зүйлийн шугаман регрессийн үндсэн ойлголт
2. Регрессийн загвар, тэгшитгэл ба Venn diagram
3. Регрессийн коэффициентийн тайлбар
4. Загвар байгуулах зарчим (model building)
5. Категорийн хувьсагч ба reference бүлэг
6. Confounding болон interaction
7. Регрессийн загварын таамаглалууд
8. Multicollinearity ба VIF
9. Үлдэгдэл болон нөлөө ихтэй ажиглалтын оношилгоо
10. R программ ашиглан олон хүчин зүйлийн регресс хийх
11. Үр дүнг тайлбарлах, хүснэгт болон графикаар тайлагнах
