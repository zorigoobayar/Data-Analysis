## Дасгалын багц

1. Хамааралтай болон үл хамааралт хувьсагчийг тодорхойлох
2. Энгийн ба олон хүчин зүйлийн регрессийн тэгшитгэл байгуулах
3. Регрессийн коэффициент, intercept болон 95% итгэлцлийн интервалыг тайлбарлах
4. Бусад хүчин зүйлийг тогтмол байлгасан нөхцөл дэх коэффициентийн утгыг тайлбарлах
5. Категорийн хувьсагч болон reference бүлэг сонгох
6. Confounding болон interaction-ийг үнэлэх
7. VIF ашиглан multicollinearity шалгах
8. Үлдэгдлийн график, leverage болон Cook's distance-ийг тайлбарлах
9. R ашиглан олон хүчин зүйлийн шугаман регрессийн загвар байгуулах
10. Загварын үр дүнг хүснэгт, графикаар тайлагнах

> Дасгал бүрт өгөгдөл, даалгавар, R код, хүлээгдэж буй үр дүн болон тайлбарыг тусдаа Markdown файлаар байрлуулна.
