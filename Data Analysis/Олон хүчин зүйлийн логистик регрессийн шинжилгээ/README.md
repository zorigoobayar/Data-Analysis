# Олон хүчин зүйлийн логистик регрессийн шинжилгээ

## Суралцах зорилго

- Хоёртын үр дүнтэй хувьсагчид логистик регресс хэрэглэх үндэслэлийг ойлгох.
- Хамааралт болон үл хамааралт хувьсагчдыг зөв тодорхойлох.
- Odds, odds ratio (OR), регрессийн коэффициентийг тайлбарлах.
- Олон хүчин зүйлийн загвар байгуулж, тохирцыг үнэлэх.
- R программ ашиглан анализ хийж, үр дүнг тайлагнах.
